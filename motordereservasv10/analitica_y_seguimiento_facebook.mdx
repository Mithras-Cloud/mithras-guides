---
title: "Facebook: configuración de Pixel ID y Page ID"
description: "Este proceso te permite configurar la integración con Facebook para habilitar el seguimiento de conversiones. Al ingresar el Pixel ID y el Page ID correspondientes, el sistema va a poder enviar datos de eventos desde el motor de reservas hacia la plataforma de Facebook, lo cual es fundamental para medir la efectividad de tus campañas publicitarias y analizar el comportamiento de tus usuarios."
---

Para configurar la integración con Facebook y empezar a trackear conversiones, seguí estos pasos:

<Steps>
  <Step title="Accedé a Configuración">
    En el menú de navegación lateral, hacé clic en **Configuración**.

    <Frame>
      <img src="https://files-public-web.s3-us-west-2.amazonaws.com/1978/video_screenshots/2026/10/01/screenshot_1790861310_0_6abe5ffe4158b.jpg" alt="Menú de navegación lateral con la opción de Configuración resaltada." />
    </Frame>
  </Step>

  <Step title="Seleccioná Integraciones">
    Dentro de la sección de **Configuración**, elegí la opción **Integraciones**.

    <Frame>
      <img src="https://files-public-web.s3-us-west-2.amazonaws.com/1978/video_screenshots/2026/10/01/screenshot_1790861310_1_6abe5ffeaffb4.jpg" alt="Menú de Configuración con la opción de Integraciones seleccionada." />
    </Frame>
  </Step>

  <Step title="Instalá la integración de Facebook">
    Buscá la tarjeta de la integración de **Facebook** y hacé clic en el botón **Instalar**.

    <Frame>
      <img src="https://files-public-web.s3-us-west-2.amazonaws.com/1978/video_screenshots/2026/10/01/screenshot_1790861310_2_6abe5ffed4dc6.jpg" alt="Tarjeta de la integración de Facebook con el botón Instalar visible." />
    </Frame>
  </Step>

  <Step title="Confirmá la instalación">
    Va a aparecer una ventana emergente de confirmación. Hacé clic en **Instalar** nuevamente para continuar con el proceso.

    <Frame>
      <img src="https://files-public-web.s3-us-west-2.amazonaws.com/1978/video_screenshots/2026/10/01/screenshot_1790861311_3_6abe5fff0fc06.jpg" alt="Ventana emergente solicitando confirmación para instalar la integración de Facebook." />
    </Frame>
  </Step>

  <Step title="Elegí el punto de venta">
    En la pantalla de configuración de Facebook, usá el menú desplegable para seleccionar el **Punto de Venta** específico que querés integrar.

    <Frame>
      <img src="https://files-public-web.s3-us-west-2.amazonaws.com/1978/video_screenshots/2026/10/01/screenshot_1790861311_4_6abe5fff47090.jpg" alt="Pantalla de configuración de Facebook con un menú desplegable para seleccionar el punto de venta." />
    </Frame>
  </Step>

  <Step title="Ingresá el Facebook Pixel ID">
    En el campo correspondiente, ingresá tu **Facebook Pixel ID**. Este ID es clave para que Facebook pueda recibir los eventos de seguimiento.

    <Frame>
      <img src="https://files-public-web.s3-us-west-2.amazonaws.com/1978/video_screenshots/2026/10/01/screenshot_1790861311_5_6abe5fff7f404.jpg" alt="Campo de texto donde se debe ingresar el Facebook Pixel ID, mostrando un ejemplo." />
    </Frame>
  </Step>

  <Step title="Ingresá el Facebook Page ID">
    Luego, en el siguiente campo, ingresá el **Facebook Page ID** de tu página de Facebook.

    <Frame>
      <img src="https://files-public-web.s3-us-west-2.amazonaws.com/1978/video_screenshots/2026/10/01/screenshot_1790861311_6_6abe5fffa7c40.jpg" alt="Campo de texto para ingresar el Facebook Page ID, con un número de ejemplo ya ingresado." />
    </Frame>
  </Step>

  <Step title="Guardá los cambios">
    Para finalizar la configuración de la integración, hacé clic en el botón rojo **Guardar**.

    <Frame>
      <img src="https://files-public-web.s3-us-west-2.amazonaws.com/1978/video_screenshots/2026/10/01/screenshot_1790861311_7_6abe5fffcf3dc.jpg" alt="Botón rojo de Guardar para finalizar la configuración de la integración." />
    </Frame>

    <Check>
      ¡Listo! Ahora tu sistema está integrado con Facebook para el seguimiento de conversiones.
    </Check>
  </Step>
</Steps>
