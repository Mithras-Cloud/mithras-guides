## Encabezado

* **Mis informes**: vuelve al listado de informes.
* **Selector de informe**: abre la lista de informes a los que tienes acceso, con un buscador, para cambiar de informe sin volver al listado.
* **Selector de establecimiento**: si tu empresa tiene más de un establecimiento, elige de cuál ver los datos.
* **Acceso**: configura quién puede ver el informe.

**\[Captura: g3\_selector\_informe.jpg]**

## Fechas y selectores

Elige el período en **Desde** y **Hasta**. Algunos informes trabajan con un solo día y muestran un único selector de fecha.

Además, cada informe puede traer selectores propios. Por ejemplo, el Informe de Reservas permite elegir **Filtrar por fecha** (fecha de venta, de preventa, check-in, check-out, etc.), la **Variante** y la **Moneda del informe**.

## Barra de herramientas

Desde la barra que está sobre la tabla puedes personalizar lo que ves:

| Botón                | Para qué sirve                                            |
| -------------------- | --------------------------------------------------------- |
| **Vistas guardadas** | Guardar y volver a aplicar una configuración del informe. |
| **Columnas**         | Mostrar u ocultar columnas.                               |
| **Filtros**          | Agregar condiciones sobre las columnas.                   |
| **Período**          | Elegir un rango de fechas rápido.                         |
| **Gráficos**         | Crear y editar gráficos con los datos del informe.        |
| **Agrupar por**      | Agrupar las filas por una columna.                        |
| **Valores**          | Elegir cómo se calculan los subtotales y totales.         |
| **Acciones**         | Exportar o imprimir el informe.                           |

Cada una de estas opciones se explica en las guías de Informes Nova.
